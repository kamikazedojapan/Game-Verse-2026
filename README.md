# 🎮 GameVerse 2026

Landing page desenvolvida para divulgar o **GameVerse 2026**, um grande evento fictício voltado ao universo dos games, eSports, tecnologia, lançamentos, competições e cultura gamer.

O projeto tem como objetivo praticar os principais conceitos de **HTML5** e **CSS3**, desenvolvendo uma página moderna, responsiva e visualmente inspirada em grandes eventos de games.

---

## 📌 Sobre o evento

O **GameVerse 2026** será um grande encontro da comunidade gamer, reunindo jogadores, desenvolvedores, criadores de conteúdo, equipes profissionais de eSports e grandes empresas da indústria.

Durante o evento, os participantes poderão acompanhar:

* 🎮 Lançamentos de novos jogos
* 🏆 Campeonatos de eSports
* 🎤 Palestras com profissionais da indústria
* 🕹️ Áreas para experimentar novos jogos
* 💻 Novidades sobre hardware e tecnologia
* 👾 Espaços dedicados à cultura geek
* 🎥 Encontros com streamers e criadores de conteúdo
* 🎁 Sorteios e experiências exclusivas

---

## 🎯 Objetivo do projeto

O objetivo deste projeto é desenvolver uma landing page utilizando inicialmente apenas **HTML e CSS**, colocando em prática conceitos fundamentais do desenvolvimento Front-end.

Entre os principais conceitos trabalhados estão:

* HTML semântico
* Estruturação de páginas
* Flexbox
* CSS Grid
* Responsividade
* Media Queries
* Pseudo-classes
* Transições
* Efeitos de `hover`
* Gradientes
* Variáveis CSS
* Organização de componentes
* Tipografia
* Hierarquia visual
